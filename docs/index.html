S.T.E.P.S.

Weekly Bible Study Platform

Scripture, Theme, Engagement, Prayer, and Share - a private weekly study community with threaded reflections, custom reactions, and admin publishing.

Source & run locally

The interactive Next.js app lives in this repository. Clone it, install dependencies, and start the dev server: 

git clone https://github.com/steps-jccc/steps.git
cd steps
npm install
npm run dev

Open http://localhost:3000. Full docs are in README.md.

What is included

  • Auth with admin / member roles
  • Weekly S.T.E.P.S. publishing and editing
  • Threaded comments and Heart / Prayer / Thinking reactions
  • Prayer requests with anonymity and moderation
  • Mobile-aware navigation for phones and laptops
